# Проект: Peleg Biderman — продвижение

## Контекст
Фитнес-тренер, специализация — бодибилдинг, работает в Ришон-ле-Ционе (локально) и онлайн по всей стране. УТП: помощь в борьбе с вредными привычками, а не просто программы тренировок.

## Уже готово
- peleg-landing.html — одностраничный лендинг на иврите (RTL), тёмная тема с оранжевым акцентом
- 7 постов для запуска Telegram-канала (готовый текст, тема: знакомство → боль → доверие → ценность → продажа)
- Инструкция по хостингу через Netlify

## Правила при работе с этим проектом
- Основной язык контента — иврит (RTL); дополнительно поддерживать английскую версию текстов/сайта, если попрошу
- Дизайн: избегать шаблонных ИИ-паттернов (градиенты, эмодзи вместо иконок, дефолтные закруглённые карточки)
- Тон текстов — как от живого человека, не общими фразами
- Кнопки связи на сайте: Telegram (t.me/PelegBIDI — ссылка реальная, не плейсхолдер) и Instagram (instagram.com/peleg.bidi, добавлен 17.08.2026 — кнопка в финальном CTA + QR-код там же). WhatsApp убрали с сайта 16.08.2026 — добавим отдельно, когда появится рабочий бизнес-номер
- Перед серьёзными изменениями сайта — сначала показать план, не менять сразу

## Доступные агенты и инструменты

- **researcher-a** и **researcher-b** — независимые исследователи фактов. Используй, когда нужно проверить конкретный факт/цифру из нескольких источников, не полагаясь на память модели.
- **truth-judge** — сравнивает результаты researcher-a и researcher-b, честно показывает совпадение, расхождение или отсутствие данных. Используй в паре с researcher-a/b для полной проверки факта.
- **skill-scout** — ищет подходящие Claude Code skills/плагины на GitHub под конкретную задачу. Только предлагает варианты со ссылками, никогда не устанавливает сам — финальное решение об установке принимаю я.
- **xlsx-populate-skill** — установленный скилл для редактирования и создания Excel-файлов (.xlsx) с сохранением исходного форматирования, объединённых ячеек и стилей. Используй при работе с таблицами и отчётами в Excel.
